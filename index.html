ANTES DO PRÓXIMO CLIQUE

Alguma dúvida?

O que esta experiência faz, e como seguir.

Preciso me cadastrar para experimentar?+

Não. O editor funciona sem login. As alterações ficam apenas na memória desta página e são descartadas ao recarregar ou restaurar o exemplo.

Minha página já fica publicada?+

Não. Esta é uma prévia local. Ela não cria uma URL pública, QR Code ou página no servidor. Você pode baixar um rascunho para guardar suas escolhas.

A plataforma é só para restaurantes?+

A proposta atende negócios de diferentes segmentos, profissionais, empresas e criadores. A Bifrost Burger é o exemplo de restaurante; os outros perfis são fictícios.

Os links são integrações com esses serviços?+

Não. Adicionar um destino como WhatsApp, Instagram ou pedidos apenas organiza um link. Isso não implica integração, sincronização ou parceria com esses serviços.

Posso guardar o que personalizei?+

Sim. Use “Guardar meu rascunho” para baixar um arquivo com o nome, a descrição, as cores e os links da sua prévia. O download não publica uma página.

Meus dados são enviados?+

Não. As alterações do editor ficam nesta página e o rascunho é preparado no seu navegador. A prévia não registra cliques nem envia seus dados para um servidor.
